# Forme

Web app installable (PWA) pour suivre mon plan d'entraînement : séances guidées avec progression automatique, minuteur de repos, routine de mobilité guidée, habitudes quotidiennes et stats.

Les données restent dans le navigateur du téléphone (localStorage) ; export/import JSON dans Réglages.

Images d'exercices : [free-exercise-db](https://github.com/yuhonas/free-exercise-db) (Unlicense, domaine public).

Test d'une date précise : `?date=2026-11-02`.
